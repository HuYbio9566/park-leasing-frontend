## 本地预览

在仓库目录运行 `python3 -m http.server 4174`，打开
`http://localhost:4174/miniprogram-view.html`。

## 发布

GitHub Pages 从 `main` 分支根目录发布。图片保留原始文件，
图标脚本随站点一同托管，不依赖第三方 CDN。
小程序手机壳布局直接保留在 HTML 中。

这是前端交互演示，并非已接入真实业务服务的生产系统。
预约、留言等不会发送给工作人员；本地浏览器状态不会自动同步给其他访问者。
会议预约、咨询、访客、报修和反馈在用户同意后保存到当前浏览器，刷新后仍可查看；
可在“我的 → 隐私与授权”清除本机记录。请使用虚构的演示联系信息。
列表和会议室详情共用同一预约弹窗，支持多时段计价、记录详情及取消本地预约。
登录、停车缴费及餐饮服务未接入真实业务接口，页面会明确提示，不会产生真实订单或扣费。
不同设备的屏幕大小、系统字体可能影响显示，桌面预览可查看完整手机壳。

第三方图标库 Lucide 0.468.0 的许可声明保留在 `vendor/lucide.min.js` 文件头部。
