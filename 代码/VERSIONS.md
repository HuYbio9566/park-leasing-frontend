## v2.0.0 — 2026-09-17 信息架构迭代

### 分工规则

底部导航找服务，首页发起办理，个人中心查询记录。

### 变更清单

1. 保留底部：首页、找空间、会议室、我的。
2. 首页快捷入口固定为：访客登记、物业报修、车辆服务、投诉建议。根据后续反馈，首页车辆入口不再显示“暂未开通”副标题，车辆页面内的演示说明保留。
3. 移除首页快捷区的空间浏览、会议预约、餐厅和公告；找空间仍由底部导航及优选空间进入，餐厅原演示页面保留但不占核心入口。
4. 公告保留独立操作，进入完整公告列表；根据后续反馈，与四个快捷服务合并为一张白色卡片，上下排列，中间浅色细分隔线，共用圆角与阴影，减少首页碎片感。
5. “我的”顶部保留预约、访客、报修记录；下方保留我的车辆、我的咨询、我的反馈、隐私与授权，去掉重复办理入口。
6. 会议室“我的预约”移至列表标题旁，取消固定绿色按钮及底部白色占位层。
7. 个人中心显示 v2.0.0 版本标识。
8. 首页轮播数据栏移除第二、三列单侧内边距，数值与说明文字按等宽列居中；分隔线独立绘制，不占用内容宽度。
9. 顶部公共导航栏下沿增加 0.5px 浅色分隔线，不影响导航栏高度。
10. 首页三张 Banner 支持点击进入各自介绍详情，提供找空间/会议室入口；保留圆点切换、自动轮播和滑动，拖动不触发详情，支持键盘打开。
11. Banner 下方三个数据项同步当前轮播内容，均可点击或通过键盘进入当前 Banner 对应详情。
12. 首页 Banner 数据卡片四周内边距统一为 8px，保持原有整体宽高与内容居中。
13. 报修、访客登记移除“* 为必填项”提示；报修位置、具体房间、联系人姓名及到访企业改为选填，提交校验同步调整，未填写信息在记录中明确标注。
14. 访客日期使用底部日历弹窗，支持月份切换、日期选择和小时/分钟输入，禁用过去日期，确认后回填，取消保留原值。
15. 反馈类型改为选填，移除反馈页“* 为必填项”提示，未选类型时以“意见反馈”保存；反馈内容及授权校验不变。

2026-09-17 增量发布：用户授权将第 13–15 项表单及日期组件调整同步至 GitHub main，并由 GitHub Pages 发布；v1 封存版本保持不变。
