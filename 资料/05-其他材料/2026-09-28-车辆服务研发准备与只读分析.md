## 2. 业务流程

| 流程 | 已确认的业务链路 | 异常及待定边界 |
| --- | --- | --- |
| 车辆绑定 | 登录、绑定企业、获得服务权限 → 填写车牌 → 提交 → 后台审核或同步 → 查看归属、状态与记录 | 重复车牌、黑名单阻止；审核与同步采用哪条路径待定 |
| 月租申请 | 查看身份对应费率、费用区间 → 临期提醒 → 提交申请 → 物业审核 → 查看处理结果 | 费率缺失转人工；提醒时间、审批节点与后续科拓同步待定 |
| 临停缴费 | 输入车牌 → 跳转或调用科拓 → 返回并展示结果 | 接口失败保留人工入口；不建设停车核心控制 |
| 访客代缴 | 输入访客车牌 → 科拓处理 → 返回结果 | 代缴资格、费用归属及结果查询规则待定 |
| 异常车辆维护 | 物业权限校验 → 新增或导入 → 启用／解除 → 留存操作日志 | 格式错误拒绝导入；生效范围、同步及解除规则待定 |

支付仅可在收款主体、订单状态、退款责任和开票方式确认后开发，不能把跳转返回直接当作支付成功。
